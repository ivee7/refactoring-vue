# Инструкция для интервьюера

> В коде оставлены комментарии с началом ```[interviewer]:```, по которым следует вести кандидата для исправления кода\
> и задавать соптуствующие вопросы

Необходимо обращать внимание на:

- naming функций, перменных и типов;
> без неконвенциальных сокращений\
> функции должны начинаться с глаголов\
> типы и классы должны начинаться с большой буквы\
> нейминг должен учитывать единственное/множественно число
- умение документировать код;
- правильность композиции:
> одна функция - одно действие
- тестируемость кода
